# 26년 5주차 웹실습 팀과제

**주제**: 식료품 쇼핑몰<br>
**개발기간**: 26.04.07 - 26.04.12까지

---

## 🛠 기술 스택 🛠
- **Language**: PHP 8.5.4
- **Database**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript
- **Server**: Apache (XAMPP / Local Environment)

## ✨ 기능 ✨
- **회원가입**
  - 폼 설계-ID/PW/NAME
  - 유효성 검사
  - 아이디 중복 확인
- **로그인/로그아웃, 세션유지/파기**
- **메인 홈 화면**
  - 네이게이션 바
  - 중앙 리스트 
  - 푸터(Footer) 레이아웃

## 👥 팀원 역할 분담
- BE: DB 설계 및 세션 보안 로직 구현
- FE/BE: 회원가입 폼 설계 및 데이터 유효성 검사
- UI/FE: 메인 UI/UX 레이아웃 제작 및 CSS 테마 적용
- DB/BE: 상품 마스터 데이터 구축 및 리스트 출력 로직 개발
